# 訂閱宇宙｜重力觀測站

一個將數位訂閱轉換成互動式宇宙星圖的 Web App，幫助使用者看懂每月訂閱支出，找出使用率低或成本過高的服務。

## 線上網站

[開啟訂閱宇宙](https://bc-huangg.github.io/subscription-universe/)

## 主要功能

- 新增、編輯與刪除訂閱資料
- 以行星大小呈現每月訂閱費用
- 查看訂閱類別與支出分布
- 依單次使用成本找出高負擔訂閱
- 模擬取消訂閱後可節省的金額
- 使用瀏覽器 `localStorage` 保存個人資料

## 專案檔案

- `index.html`：完整網頁，包含 HTML、CSS 與 JavaScript
- `訂閱宇宙 Web App 規格書.pdf`：作品規格書

## 使用方式

直接開啟線上網站即可操作；也可以下載專案後，以瀏覽器開啟 `index.html`。

## 技術

HTML、CSS、JavaScript、GitHub Pages
